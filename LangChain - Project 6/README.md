# 🏗️ NotebookLM Clone - Agent Explorer

חיקוי ממוקד של כלי המחקר העוצמתי מבית גוגל (NotebookLM), המבוסס על סוכן אוטונומי (LLM Agent) המבצע מחקר עצמאי ברשת, כולל נקודת עצירה לאישור אנושי (Human-in-the-Loop) וממשק משתמש אינטראקטיבי.

---

## 🎯 מטרת הפרויקט
הפרויקט מדגים בניית סוכן חכם בעל אוטונומיה להחליט כיצד וכמה לחפש מידע באינטרנט על בסיס נושא המוגדר על ידי המשתמש. הסוכן עוצר לאחר שלב איסוף המקורות, מציג אותם למשתמש, וממשיך לניסוח סיכום מקיף רק לאחר קבלת משוב ואישור אנושי.

---

## 🛠️ טכנולוגיות וכלים
* Python (שפת הפיתוח המרכזית)
* LangGraph / LangChain (ניהול הגרף, הסוכן ולולאת ה-ReAct)
* Tavily Search API (מנוע חיפוש ייעודי וממוקד עבור סוכני AI)
* OpenAI API (GPT-4o-mini) (מודל השפה המשמש כמוח מאחורי הסוכן)
* Streamlit (ממשק משתמש אינטראקטיבי ומהיר בדפדפן)

## 🚀 הוראות התקנה והרצה

### 1. התקנת חבילות ותלויות
פתחי את הטרמינל בתיקיית הפרויקט והתקיני את כל הספריות הנדרשות מתוך קובץ ה-requirements.txt באמצעות הפקודה:
pip install -r requirements.txt

### 2. הגדרת משתני סביבה
צרי קובץ בשם env. בתיקיית השורש של הפרויקט והגדירי בתוכו את המפתחות שלך באופן הבא:
OPENAI_API_KEY=your_openai_api_key_here
TAVILY_API_KEY=your_tavily_api_key_here

*שים לב: הגישה ל-API של OpenAI דורשת יתרה חיובית בחשבון המפתח (Billing) על מנת למנוע שגיאות חריגה מהמכסה (Error 429).*

### 3. הרצת האפליקציה בממשק ה-UI
כדי להפעיל את ממשק המשתמש בדפדפן, הריצי את הפקודה הבאה בטרמינל מתוך תיקיית הפרויקט:
python -m streamlit run app.py

## 🔄 זרימת העבודה במערכת (Workflow)

1. הזנת נושא: המשתמש מזין נושא למחקר בתיבת הקלט בממשק ה-UI ולוחץ על "צא לדרך".
2. חיפוש אוטונומי: הסוכן מנתח את הבקשה, מנסח שאילתות ומפעיל את מנוע החיפוש Tavily באופן עצמאי כדי לאסוף מקורות רלוונטיים.
3. עצירה לביקורת אנושית (Human-in-the-Loop): באמצעות מנגנון ה-Interrupts וה-Checkpointer של LangGraph, המערכת עוצרת את הריצה ומציגה למשתמש את הקישורים והתקצירים הגולמיים שנמצאו.
4. אישור וסיכום סופי: המשתמש מזין הנחיות סינון וממשיך את הריצה. הסוכן מתעורר מנקודת העצירה, מעבד את המקורות המאושרים ומציג סיכום מקיף ומאורגן בפורמט Markdown.
