# 🏗️ NotebookLM Clone - Agent Explorer

חיקוי ממוקד של כלי המחקר העוצמתי מבית גוגל (NotebookLM), המבוסס על סוכן אוטונומי (LLM Agent) המבצע מחקר עצמאי ברשת, כולל נקודת עצירה לאישור אנושי (Human-in-the-Loop) וממשק משתמש אינטראקטיבי.

## 🎯 מטרת הפרויקט
הפרויקט מדגים בניית סוכן חכם בעל אוטונומיה להחליט כיצד וכמה לחפש מידע באינטרנט על בסיס נושא המוגדר על ידי המשתמש. הסוכן עוצר לאחר שלב איסוף המקורות, מציג אותם למשתמש, וממשיך לניסוח סיכום מקיף רק לאחר קבלת משוב ואישור אנושי.

## 🛠️ טכנולוגיות וכלים
* **Python** (שפת הפיתוח המרכזית)
* **LangGraph / LangChain** (ניהול הגרף, הסוכן ולולאת ה-ReAct)
* **Tavily Search API** (מנוע חיפוש ייעודי וממוקד עבור סוכני AI)
* **OpenAI API (GPT-4o-mini)** (מודל השפה המשמש כמוח מאחורי הסוכן)
* **Streamlit** (ממשק משתמש אינטראקטיבי ומהיר בדפדפן)
